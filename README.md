# CARTPAY DIGITAL HUB — website + Vercel Python API

This project includes the website's original assets, the updated CARTPAY DIGITAL HUB branding/logo, and Python serverless endpoints for Vercel.

## Run locally

1. Install Python 3 if needed.
2. Open this folder in VS Code.
3. Run `python serve.py` in the terminal.
4. Open `http://127.0.0.1:8137/`.

The local `serve.py` is for local testing. Vercel does **not** run a long-running Python server with `python serve.py`; it runs files in the `api/` folder as serverless functions.

## Deploy to Vercel — step by step

1. Extract this ZIP.
2. Create a new GitHub repository (for example, `cartpay-digital-hub`).
3. Upload the extracted project files and folders to the repository root. Make sure `index.html`, `products.json`, `vercel.json`, `api/`, `_next/`, `logo.png`, and `favicon.ico` are all at the root level.
4. Sign in to Vercel and choose **Add New → Project**.
5. Import the GitHub repository.
6. For this project, choose **Other** as the framework preset if asked. Leave the build command empty and the output directory as `.` / root (do not set a Next.js build command).
7. Click **Deploy**. The website and product catalogue should deploy. `vercel.json` routes `/sb/rest/v1/products` to the Python endpoint in `api/products.py`.
8. To make order submissions save permanently, create a Supabase project and create the table below.
9. In Vercel, open **Project → Settings → Environment Variables**. Add:
   - `SUPABASE_URL` = your Supabase project URL
   - `SUPABASE_SERVICE_ROLE_KEY` = your Supabase service-role key
   Add them to Production (and Preview if needed), save, then redeploy. Never put the service-role key in HTML, JavaScript, GitHub, or a public file.
10. In Supabase SQL Editor, run:

```sql
create table if not exists public.orders (
  id bigint generated by default as identity primary key,
  order_id text not null unique,
  customer_name text not null,
  customer_mobile text not null,
  customer_location text,
  product_id text not null,
  created_at timestamptz not null default now()
);
```

11. Test the live site: products should display; submit a test enquiry and check that a row is added to `public.orders`. The site will show an explanatory error until the two environment variables and table are configured.

## Important deployment notes

- `serve.py` is only a local development server. Do not configure Vercel to run `python serve.py`.
- Vercel Python functions are serverless and their local filesystem is not durable. This project saves orders through Supabase instead of writing to `orders.json`.
- `products.json` is the local catalogue. Edit it to change the product list/prices, then commit and redeploy.
- The service-role key is secret. Use it only as a Vercel Environment Variable; do not share it.
